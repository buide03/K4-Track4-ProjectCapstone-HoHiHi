# Camera TTC UI

Giao diện web độc lập, dựa trên repo buide03/K4-Track4-ProjectCapstone-HoHiHi.

Chạy từ thư mục gốc repo: `python3 -m http.server 8090 --directory ui`

Chức năng: demo TTC, phát/tạm dừng/tua, tải video cục bộ, vẽ và xuất polygon, đổi ngưỡng, ba kịch bản mô phỏng, xuất CSV demo, điều hướng ba màn hình, responsive.

Chưa kết nối backend Python/YOLO. Video người dùng không được nhận diện hoặc tính TTC. Không gửi video lên máy chủ. Biểu đồ là đường minh họa tĩnh; số liệu demo thay đổi theo thời gian và cấu hình.
